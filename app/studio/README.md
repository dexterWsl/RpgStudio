# rpgStudio：通用剧情编辑器

给任意 **RPG Maker MZ / MV** 工程用的剧情编辑器：用来看懂一个游戏的剧情结构、改台词、加事件。不认识任何具体游戏——约定都写在 `profiles/` 里。

## 启动

**只想在自己电脑上用**：用仓库根目录的「启动.cmd」，界面是 `app\studio\` 这一套，自带 Node.js、没有登录，详见 [`../../使用说明.txt`](../../使用说明.txt)。

```bash
# 直接改游戏目录（每次保存前自动备份到 backups/studio/）
node app/studio/server.js --project "D:\Games\我的游戏"

# 改一份工作副本，不碰游戏本体
node app/studio/server.js --project "D:\Games\我的游戏" --data "D:\work\我的游戏-data"

# 什么都不指定：打开后在「工程」里导入游戏
node app/studio/server.js
```

打开 <http://127.0.0.1:8700/studio>。其它参数：`--port 8700`、`--host 127.0.0.1`、`--profile generic|example`、`--read-only`、`--projects <导入的游戏放哪>`（默认 `app/studio/data/projects/`）。

`handler.js` 也可以挂到别的 http 服务上（见文末「挂到别的服务上」）。

## 能做什么

| 地方 | 内容 |
| --- | --- |
| 概览 | 自动执行 / 并行处理的事件页和公共事件（剧情从哪里开始推进）、台词最多的地方、只被判断却没人去打开的开关 / 变量 |
| 地图 | 按 MapInfos 的层级列出；用游戏自己的图块集渲染地图，事件显示成行走图（拖动换位置，点空格子新建）。三种模式：事件 / 图块 / 区域（见下面「地图编辑」） |
| 事件 | 每一页「什么时候出现」（开关、变量、独立开关、物品、角色）和触发方式；阅读视图 / 改台词；新建、复制、删除、挪页；改条件 |
| 公共事件 | 触发方式、谁调用了它；阅读 / 改台词；新建（优先用空着的槽） |
| 开关 / 变量 | 改名、新建；每个被判断几次、被设置几次、脚本里用到几次；「只判断没人改」「只改没人判断」筛选；点一下看全部引用；「人物」一列 = 主要是谁的戏在用，可以按人物筛 |
| 人物 | 数据库角色 + 只在台词里出现的说话人；每个人说了几句、出现在哪些页、用到哪些开关 / 变量；新建人物、改资料、换小人 / 头像 |
| 小人库 | 行走图 / 头像，每个小人用在哪里；上传、替换其中一个、调整位置 / 大小 / 翻转；正面、侧面、背面三张站立图直接拼成行走图 |
| 剧情进度 | 选天（章节）→ 选地图 → 在地图上看、改、新建：左边是天 / 章节的时间线，右边是这一天的事件顺序（必要的红、支线绿），点空格子新建场景；也能切成列表看。按天 / 按章节 / 按开关链 / 按地图，加几条支线（见下面「剧情进度」） |
| 场景 | 一段剧情（台词 + CG）存成一个场景：放到地图上的某一天，或者挂到某个选项下面；改一处，用到它的地方一起变（见下面「场景」） |
| 回想房 | 一张地图当回想房：每个回想播什么、怎么解锁、正常玩解锁不了的；挑已有的剧情加进来（完整播放 / 只看图）；还没进回想的 CG 剧情 |
| 工程 | 系统里放多个游戏，顶栏切换；导入游戏（上传 zip / 本机文件夹）、改名、导出改过的文件、移除 |
| 导入素材 | 素材包 zip、一堆图片 / 声音、整个文件夹：自动分类、预览里改分类和名字、同名改名 / 覆盖 / 跳过，按游戏加密 |
| 搜索 | 台词、选项、事件名、公共事件名、地图名、开关 / 变量名、注释、脚本 |
| 结构检查 | 每一页的缩进与分支配对，引用的开关 / 变量 / 公共事件 / 地图 / 图片是否存在 |

文字里出现的「开关 3「xx」」「变量 5」「公共事件 2」都可以点，右边会列出它在哪里被用到。

## 工程：导入游戏

系统里可以放好几个 RPG Maker 游戏，顶栏点游戏名切换，切过去以后整个编辑器（地图、事件、人物、回想房……）都是那个游戏的。

- **内置工程**：启动时 `--project` 指的那个；不指定就没有内置工程，全用导入的。
- **导入**（顶栏菜单「导入游戏…」或「工程」页）：
  - **上传 zip**：RPG Maker 工程或者部署好的游戏都行，里面要有 `data/System.json`（或 `www/data/System.json`），套几层文件夹都能找到。
    zip 里的中文文件名按 UTF-8，不是的按 GBK 解（Windows 上压的）。rar / 7z 要先转成 zip；只有 exe 的游戏是打包加密过的，要先解包。
  - **本机文件夹**：填运行服务那台电脑上的路径（可以填上一层，往下找 3 层）。可以选「复制一份进系统」（推荐）或「直接改原文件夹」（每次保存前自动备份）。
- 复制进来的游戏放在 `studio/data/projects/<编号>/`（云端放在每个用户自己的工作区 `projects/` 里，别人看不到）。
- **导出改过的文件**：导入以后改过的 data / img / audio / plugins.js 打成一个 zip，覆盖回原游戏就行。
- **移除**：复制进来的连文件一起删；直接改原文件夹的只从列表里拿掉。当前工程打不开（文件夹被挪走了）时会自动去「工程」页让你换一个。
- 每个工程的设置（游戏配置、剧情图片编号段、剧情进度的分法）各存各的；备份放在 `projects/_backups/<编号>/`。
  游戏文件夹里有 `rpgstudio.json`（用编辑器新建的游戏都有）时，设置存在游戏里，挪文件夹、打包给别人都跟着走；导入的别人的游戏不往里写东西。

## 新建游戏

「选择游戏」页的「新建游戏」：从零做一个 MZ 游戏。

- **引擎从哪拷**：RPG Maker MZ 自带的空白工程（Steam 版 / 官网版装在常见位置会自动找到，`…\RPG Maker MZ\newdata`）、列表里已有的 MZ 游戏，或者别的文件夹。编辑器本身不带引擎和素材。
- **拷什么**：`js/`（插件不拷，新游戏从干净的插件列表开始）、字体、样式、图标、`index.html`；数据库从零生成：一个主角、一个职业、必需的技能 / 状态、一张空地图、中文用语，中文游戏用系统里的中文字体。
- **素材**：勾「连图块、行走图、声音一起拷」= 连 RTP 素材和图块集定义一起拷（RPG Maker 自带的空白工程推荐；别人的游戏别拷）。
  不拷也能直接跑：窗口、按钮、影子这几张系统图会画朴素的占位图，之后在「导入素材」里换。
- 建好以后切换过去；放在 `projects/<编号>/`，跟导入的游戏一样。

## 试玩

顶栏「▶ 试玩」：在浏览器里直接跑这个游戏（MZ 本来就能在浏览器里跑），不用装 RPG Maker，也不用 nw.js。地址是 `/play/<工程编号>/`。

- **从标题画面开始** / **跳过标题，直接开始新游戏**
- 地图页「▶ 在这里试玩」：从这张地图开始（开始地图就站在开始位置，别的地图从中间找一格能站的）
- 剧情进度页「▶ 从这一段试玩」：进度变量（开关链上的开关、时段开关）先设成选中的那一段，从工作台正在看的那张地图开始
- 地址参数（自己拼也行）：`?new=1` 跳过标题；`?map=3&x=5&y=8&d=2` 从哪开始；`&v12=3&s5=1` 开始前把变量 12 设成 3、开关 5 打开
- 只读：只发游戏文件，不能写。存档在浏览器里，跟游戏文件夹里的 `save/` 不是一份。试玩时附加的小插件只在发出去的 `js/plugins.js` 里，游戏文件不动。

### 双击启动器

不开编辑器也想玩：「游戏设置」页点「做双击启动器」，游戏文件夹里会多出 `开始游戏.cmd` 和 `js/rpgstudio_launcher.cjs`（用编辑器新建的游戏自带）。

- 双击 `开始游戏.cmd`：在本机开一个只读的小网页服务器（只听 127.0.0.1），有 Edge / Chrome 就开成没有地址栏的单独窗口，没有就用默认浏览器。玩的时候别关那个黑窗口。
- 要 Node.js：依次找游戏文件夹里的 `runtime\node\node.exe`、做启动器时 rpgStudio 本地版自带的那个、游戏在本地版 `data\games\` 里时往上三层的、电脑上装的。都没有会提示怎么办。
- 端口按游戏编号固定（8730 起），存档在浏览器里，下次双击还在；跟编辑器「▶ 试玩」的存档不是一份。参数：`--browser` 用默认浏览器、`--port 8800` 换端口、`--no-open`。
- 发给没装 Node.js 的人：用 RPG Maker MZ 打开 `game.rmmzproject`，「文件 → 部署」做成 Game.exe。

## 游戏设置

左栏「游戏设置」：游戏名、从哪开始（地图和格子）、标题画面的图和音乐、标题上要不要写游戏名、菜单里有哪些项（物品 / 技能 / 装备 / 状态 / 整队 / 保存）、系统音效（光标、确定、取消、不行）、窗口色调、队伍跟在后面走。

## 图块集

左栏「图块集」：新建 / 改名，每页（A1~A5、B~E）用 `img/tilesets` 里的哪张图，每一格的设置：

- **通行**：点一下切换 ○ 能走 → × 挡住 → ☆ 盖在人物上面（树冠、路灯顶这种）
- **柜台**（隔着能说话：店员站在柜台后面）、**草丛**、**梯子**
- A1~A4 自动元件一种 48 个编号一起改；保存只发改过的格子。

## 出入口和路人（接口）

- `POST map/door`：在一格放出口，走上去换地图；默认在到达的那一格也放一个回来的出口，到达位置自动找出口旁边能站的格子（不会一落地又踩到出口）。可以带音效、出现条件。
- `POST map/crowd`：在一片地方能站人的空格子上随机放一群路人：随便走走，搭话说给的台词里的一句（「名字：台词」也行）；可以只在剧情进度的某几段出现。
  - 路人默认**能穿过去**（`through: false` 才挡路）。
  - `group: { count, size }`：不散着走，**两三个人一堆**面对面站着聊（2 个人面对面；3 个人围着中间一格），堆跟堆之间至少隔一格；台词的一项是这一堆人的一段对话（几句换行隔开），跟谁搭话都说这一段。
  - `chatter`：头上冒的**闲聊**（`#飘字`），一堆人一组、轮着冒；放在一个看不见的并行事件里，剧情在演、对话框开着的时候不冒。
  - `stages: [{ seg, until, lines, chatter }]`：**按剧情进度换台词**：第 seg 段起用这一组，用到下一组（或 until）为止；最早那一组之前、until 之后人不在。
- 事件页能设移动方式：不动 / 随机走 / 靠近主角，速度、频率、踏步、朝向固定、穿透（`page/settings`）。

## 导入素材包

左栏「导入素材」。拖进来：素材包 zip、一堆图片 / 声音，或者整个文件夹（会保留目录结构，分类时要看）。

- **自动分类**：路径里有 RPG Maker 的目录名（`img/characters`、`img/faces`、`audio/bgm`……）就照它；否则看名字和尺寸：
  `$` / `!` 开头 → 行走图；名字带 face 或 144 一格的 4×2 图 → 头像；`_A1`~`_A5`、`_B`~`_E` → 图块；12×8 格（宽度 800 以下）→ 8 人行走图；
  像 3×4 格的小图 → 单人行走图（名字前补 `$`）；其它图 → 图片（立绘 / CG）。声音按目录 / 名字分 BGM / BGS / ME / SE，猜不出按大小。
  每个文件都写着「为什么分到这里」，可以在预览里改分类和导入后的名字（图片可以带子文件夹：`CG/场景1`）。
- **格式**：RPG Maker 只认 PNG 和 ogg / m4a。jpg / webp 会在浏览器里先转成 PNG；别的游戏加密过的图（`.png_` / `.rpgmvp`）会先解开再导入。mp3 / wav 和加密的声音不能导入。
- **同名**：改名（加 `_2`，默认）/ 覆盖（先备份到 `backups/…/assets-时间/`）/ 跳过。
- **加密**：游戏的图片 / 声音是加密的，就用游戏的密钥加密成 `.png_` / `.ogg_`（MV 是 `.rpgmvp` / `.rpgmvo`）。
- 云端：图片放进自己的工作区，导出改动包时一起打包（所有 img 子目录）；声音 / 视频暂时不支持。
- 上传的文件先放在系统临时目录的暂存区，导入完就清掉，一天没动的也会清掉。

## 页面怎么保持清爽

默认只摆出要看的东西，复杂的细节收起来，要改的时候再展开：

- **阅读视图只看剧情**：台词、选项、条件分支、传送、调用公共事件照常显示；中间连续的「后台操作」（改开关变量、画面、图片、声音、等待、脚本、插件、注释）
  折成一行「N 条后台操作（数值 3 · 图片 2）」，带图片缩略图，点开看每一条。只有一条的就淡淡地显示。右上角勾「显示全部指令」看原样（记住选择）。
- **分支可以收起**：点「如果… / 选了… / 否则」那一行，收起它下面的内容；「收起所有分支」只留最外层，像目录一样。
- **事件头一行写完**：小人 · 出现条件（多条只写第一条，「还有 N 个条件」点开）· 触发方式；优先级、独立开关这些在「细节」里。
  复制 / 删除这一页、删除事件、新建子地图、复制 / 删除地图收在「⋯」菜单里。
- **改条件弹窗**：只显示勾上的条件，其它用「＋ 加条件」拿出来；自动执行的提示只在选了自动执行时出现；优先级在「更多设置」里。
- **长列表**只显示前几个，「显示全部」再展开；概览里「这个游戏的约定」「可能走不到的条件」可以收起（记住状态）。

## 地图编辑

打开一张地图，切到「图块」或「区域」：

- **调色板**：这张地图图块集的 A / B / C / D / E 页（只显示有图的页），可以拖动框选多格当一个「章」盖。
- **工具**：铅笔、矩形、油漆桶、橡皮、吸管（右键也是吸管）。快捷键 B / R / G / E / I，Ctrl+Z 撤销、Ctrl+Shift+Z 重做、Ctrl+S 保存，Ctrl+滚轮缩放，中键拖动画面。
- **自动元件**：草地、水、墙这类会按周围格子自动接边（地图边缘算作相连），跟 RPG Maker 一样；改一格会重算它和周围一圈。
- **图层**：默认「自动」：A 页画在地面层，并清掉这一格 B~E 的东西；B~E 叠在上层（第 3 层空着放第 3 层，否则放第 4 层）。也可以手动指定只写第 1~4 层。
- **区域**：刷区域编号 0~255（给插件、遇敌用）。
- **保存**：整张地图一起存，保存前自动备份。打开后这张地图在别处被改过（另一个窗口、简单模式）会拦下，不会覆盖。
- **地图本身**：地图属性（名字、显示名、大小、图块集、BGM、远景、备注）；新建子地图、复制地图（连事件）、删除地图（有子地图或是开始地图时不能删，删前提示有几处传送到这里）。改小地图时如果有事件会落到外面，会先拦下。

画法照 MZ 引擎（`web/tilemap.js`，浏览器和 Node 共用）：一格的绘制顺序（☆ 图块在最上、阴影、A2 桌沿）、自动元件的拼法、A1 水面 / 瀑布、A3 / A4 墙都按 `rmmz_core.js`；
远景、事件小人也按游戏里的样子画；加密的 `.png_` / `.rpgmvp` 图块集也能读。图块画法用 22 张地图和游戏自带的 Mapshots 截图逐像素核对过，图块完全一致。
自动接边规则也拿 13294 格现成自动元件对过，99.4% 一样。

## 人物和数值

**人物**从两处来：数据库里的角色（Actors.json），和只在对话框名字里出现、不是角色的说话人。一个人算「在这一页」：

- 说话：对话框的名字是 `\N[n]` 或角色名，或者对话框用的是这个角色的头像
- 出场：事件页的图像是这个角色的行走图

**相关数值**：这个人出现的那些页里，被判断、被修改的开关 / 变量。每页每个数值只算一次，出现的页越多越靠前；
到处都用的（天数、坐标）分数低。名字里带这个人名字（中文名、英文名都认）的加分；**手动关联**的排最前，
存在角色备注里：`<RpgStudioLinks:var 12,switch 3>`（游戏不认这个标签，不影响运行）。

- 人物页：相关数值两列，每个可以「关联 / 取消关联」；「给 TA 新建」= 新建一个名字叫「人物名·xx」的开关或变量，并自动关联。
- 开关 / 变量页：「人物」一列是反过来算的——用到这个数值的页里，哪个人出现的比例比 TA 平时高得多；主角几乎每页都在，不会因此占掉所有数值；
  好几个人都差不多的显示「多人共用」。右上角可以按人物筛，按相关程度排序，「新建」变成给这个人新建。
- 改事件页条件：弹窗最上面列出这个事件里的人常用的开关 / 变量，点一下就填进条件（开关先填开关 1，已经占了就填开关 2）；
  没有合适的可以就地新建（选属于谁），建好直接选上。同一个弹窗里也能换这一页的图像。

## 剧情进度

不同的 RPG 推进方式不一样：有的按天切换（一个天数变量 + 白天 / 夜晚开关），很多 RPG 按主线事件切章节（一个进度变量越设越大，或者一串「第 N 章完成」开关）。
这里只是「怎么看」，不改游戏数据（改条件时点「填进条件」除外）。

- **从零开始**：还没分阶段的游戏（剧情进度页上方有提示卡片），或者「设置 → 从零开始…」：选按天 / 按章节、要几天几章，一步建好——
  新建变量「天数」/「主线进度」（也可以用已有的），左边出现第 1 ~ N 天（章）；勾「开局就是第 1 天」会在开始地图放一个看不见的自动事件，新游戏开始时把变量设成 1（只跑一次）；
  按天的还可以勾「分白天 / 夜晚」（新建两个开关，开局白天开）和「过一天」（场景库里一个「过一天」：淡出 → 天数 +1 → 淡入，建好后接着点地图上的格子放上去，每天都在、可以反复用）。
  按章节的：每一章最后那段剧情放的时候，「播完以后」选「推进到」下一章。
- **主线（一次选一种）**：
  - **按天**：一个变量记第几天，可以再选几个开关当时段（工作 / 自由时间 / 夜晚……）。时间线每天一行，时段分成几列。
  - **按章节**：一个进度变量，按它的值切成几段（默认每个用到的值一段，可以合并、改名）。
  - **按开关链**：一串开关，开一个算进下一章。
  - **按地图**：不分进度（没认出来时就是这个）。
- **支线（几条都行）**：每条一个进度变量（某个角色的剧情线、某个任务），按值分步，时间线页上一条一个标签。
- **怎么来的**：工程设置里存的 > 游戏配置（`profiles/` 里的 `progress`）给的 > 自动识别（名字像天数 / 进度、被拿来当页条件、会被加 1 或设成越来越大的值的变量；名字带「第 N 章」的开关）。页面右上角「设置」可以改（云端只有管理员能改）。
- **怎么算**：每个事件从最后一页往前找，看每一段（× 每个时段）显示哪一页——条件都在进度上而且满足 = 一定显示；还有别的条件（独立开关、别的开关……）= 「不一定」。页里的「如果 天数 = 3」分支也算进那一段。同一页出现在连着的好几段只在第一段列一次（写着「到第几天」），每一段都有的收在「每天都有的」里。
- **地图工作台**（左栏「剧情进度」默认就是它）：
  - 左边一列天 / 章节，做成一条时间线，旁边的数字是那一天有几件事；按天的游戏上面可以切时段（全天 / 工作 / 自由时间 / 夜晚）。
  - 上面一排是这一天有剧情的地图（数字 = 几件事），点哪张看哪张；换一天时，现在这张图没剧情就自动跳到剧情最多的那张。
  - 地图上只画这一天会出现的事件（「也画这时不在的事件」可以打开）。**红框 = 必要**：一进地图自动播 / 并行处理，或者会把剧情推进下去（改天数、开下一章的开关、切时段，调用的公共事件里这么做也算）；**绿框 = 支线**：要玩家自己去找的。跟进度无关、每天都一样的事件淡一点。
  - 右上角「第 N 天的事件顺序」：按时段分组，时段里 自动播的 → 支线 → 推进的；条件只写进度以外的（「需要：开关 52 为开」）。点「查看详情」换到那张地图、选中那个事件，右边看那一页（公共事件里的分支就直接显示那个公共事件），「← 事件顺序」回来。
  - 点地图上的事件：右边显示这一天显示的那一页，可以就地读、改台词、在选项里关联场景；如果这一页只是播一个场景，右边直接是场景的台词，改的就是场景本身。
  - 点空格子：「在这里新建场景（第 3 天 · 夜晚）」，见下面「场景」。
  - 左边时间线底下「＋ 新建一天」（按章节 / 开关链的游戏是「＋ 新建一章」）：在主线最后加一段。按天 = 天数 +1；按章节 = 进度变量从多少起（默认最后一段 +1）；
    按开关链 = 新建一个开关「进入 …」（也可以选已有的）。加完会选中新的一段。玩家要能进来：在上一段放一个场景，选「播完推进到」这一段。
  - 「列表」= 原来的时间线（每一段新出现哪些剧情、从哪进来），支线在列表里看。
- **算「这一天的剧情」**：某一页只在不到一半的段里出现、而且有台词 / 图 / 调用，才算那几段专门的剧情（只看时段、每天都一样的不算）；「不一定」的页后面藏着的页也看。另外在这一段会把剧情往前推的页一定列进事件顺序（每天都在的床「过一天」、切时段的也算）。
- **顶栏「进度」**：跟工作台选的是同一个。选一个进度（和时段），地图页上那时不出现的事件变暗，点事件直接打开那时显示的那一页；事件页的页签上标出那一页，每页写着在哪几天 / 哪几段出现。
- **改条件「按进度放」**：选一段（和时段）点「填进条件」，填成「变量 ≥ 那段的值」+ 时段开关（开关链就填那个开关）。页条件只能写「≥」，所以放在第 3 天 = 第 3 天起都出现，直到后面的页盖过它。

自检：`node studio/test/progress.js <游戏目录>`（只读）会打印认出来的推进方式和每条时间线的规模，并核对地图亮暗和事件页标注是否一致。

## 场景

一个场景 = 一段剧情（台词 + CG，也可以有选项），存成一个公共事件（第一条是注释 `<RpgStudioScene>`，阅读视图里不显示）。地图上的事件、选项、回想房都去调用它，改一处各处一起变。左栏「场景」是场景库。

- **新建**：顶栏或剧情进度页的「＋ 新建场景」。写名字和台词（一行一句「名字：台词」，`#图 图片名` 从这句开始显示 CG，`#清图` 关掉，`#选项 去 | 不去` 下面每行用 `#1` `#2` 开头写各自的内容）；人物名字和 CG 可以点着插入（CG 是一格格大缩略图）。写法有问题就报错，不会留下半成品。
- **预览**：新建场景的弹窗右边边写边显示每一句、每张 CG（图直接显示，找不到的图报出来）。「▶ 播放」像游戏里一样演一遍：黑底放 CG、下面对话框（名字、头像、窗口样式照原样），
  点画面 / 空格走一句，遇到选项点着选、遇到条件分支问「成立吗」，调用的公共事件往里展开；播放叠在弹窗上面，Esc 关掉回到弹窗。
  阅读视图上面也有「▶ 预览」（改台词时播的是还没保存的版本），场景库每张卡片也能预览。
  - 插件放的图也能播：VisuMZ 立绘插件（VNPictureBusts）的立绘入场 / 换表情 / 移动 / 退场（位置 0~10 照游戏里的插件设置算，入场退场会滑进滑出），
    视频层插件（LayeredVideoPlayer）的 CG 视频（静音循环），VisuMZ 文字窗口插件的文字窗口。别的插件指令播放时跳过。
- **放到地图**：在剧情进度的地图上点空格子（或者场景库 / 场景页的「放到地图」再点空格子）。会在那个格子新建一个事件：
  - 第 1 页：这一天（这一段）、这个时段出现，播场景；「只播一次」就顺手打开独立开关 A。
  - 第 2 页：勾了「只在这一天」，下一天（下一段）起换成空白页（看不见、碰不到）。最后一段没有这一页。
  - 第 3 页：只播一次 → 独立开关 A 开了以后是空白页。
  - 怎么开始：走过去按确定键 / 碰到就开始 / 一进地图自动播（自动播一定只播一次，不然会一直重复）。可以选一个小人，不选就是看不见的触发点。
  - 播完以后：可以「推进到」后面某一段——第 1 页播完场景再把进度变量设成那一段的值（开关链就打开那一段的开关），这个事件在事件顺序里就是红的（必要）。
  - 按开关链的游戏用链上的开关当条件；按地图的游戏没有条件。格子上已经有事件的不能放，换个空格子，或者在那个事件的选项里关联。
- **关联到选项**：阅读视图里每个「选了 xxx」旁边有「关联场景」，挑一个场景（或者当场新建一个），就在那个选项分支最后插一条「调用公共事件」：选这个选项时先播原来的台词，再播场景。已经关联的可以取消，取消后那一页跟原来一模一样。场景里自己的选项也能关联别的场景（不能调用自己）。
- **场景库**：每个场景的第一句、几句台词、几张图（缩略图）、被哪里用到（第几天哪张图哪个格子 / 哪个选项）；没被用到的可以删除（清空那个公共事件槽，下次新建会用）。已有的公共事件可以在它的页面「⋯ → 加进场景库」，移出时只拿掉标记、内容不动。

## 回想房

回想房就是一张地图，里面每个入口事件是一个回想：走过去按确定，把一段剧情完整再看一遍，或者只看 CG。

- **哪张地图**：地图备注里有 `<RpgStudioRecallRoom>` 的；没有就认名字带「回想 / 图鉴 / 画廊 / Gallery」的。页面里可以换一张，或者「新建回想房」（照一张现有地图的图块、大小、BGM，不带事件）。
- **每个回想一张卡片**：小人、标题、播的是什么（几段选项 / 调用哪个公共事件）、CG 缩略图、怎么解锁：
  - 入口页的开关条件；或者选项文字前面的 `<<[!s[207]]>>` 这种条件（WD_ConditionalChoice 这类插件：条件成立时锁住，`!s[N]` = 开关 N 要开）
  - 每个解锁开关在哪里打开；回想房以外没有地方打开 = **正常玩解锁不了**（单独筛出来；只有回想房里「全解锁」会打开的也会注明）
- **解锁**：单个或全部改成一开始就能看——清掉入口的开关条件和选项前面的 `<<条件>>`；「第几天」这种变量条件留着。
- **加回想**（回想房页的「＋ 加回想」、事件页「⋯ → 把这一页加进回想房」、公共事件页「⋯ → 加进回想房」、缺口列表的「加进回想」）：
  从所有有台词或 CG 的事件页 / 公共事件里挑，可以一次挑好几个，每个改标题、选小人；解锁选「一开始就能看」或「看过原剧情才解锁」。
  - **完整播放**：台词、CG、音乐、选项、分支照原样。地图事件页和公共事件连同嵌套调用都复制成专用公共事件（备注里记着来源，原剧情改了以后点「重新复制」同步）。
  - 地图事件和公共事件都复制为专用副本，递归处理嵌套公共事件调用；原剧情保持独立。过滤传送、打开存档 / 回标题 / 游戏结束、暂时消除事件、指向原地图其它事件的移动 / 动画 / 气泡（玩家和「本事件」照留）。
  - 入口是「播放 / 只看图 / 算了」。播放：先用脚本记下开关、变量、独立开关、物品和金钱，播完恢复，**不影响存档进度**；再淡入（原剧情最后是淡出时）、清掉显示过的图、恢复回想房的 BGM。
  - **只看图**：按原顺序只放图片和画面效果（叠图、移动、淡入淡出），台词全去掉，原来每段台词的位置换成透明的「点一下继续」，中间没换图的合并；另存成一个公共事件。剧情里没有图就不出这个选项。
  - 看过才解锁：新建一个开关「回想·标题」，在原剧情开头打开；入口第 1 页「还没看过这段剧情」，第 2 页要这个开关。
  - 位置自动挨着现有的回想入口找能站人的空格子（看图块的通行设置）。
- **拿掉**：删入口事件；复制出来的公共事件没有别人调用就一起清空，原剧情不动。
- **还没进回想的 CG 剧情**：一页里有 2 张以上剧情图（编号在「剧情图片」范围里），而且大多没在回想房出现过。

## 小人库

- 行走图：普通图 4×2 个人，每人 3 列（姿势）× 4 行（朝向 下左右上）；名字以 `$` 开头的图只有一个人；`!` 开头是物件（不往上抬 6 像素）。头像图 4×2 个，每个 144×144。
- **上传**：拖一张 PNG，按尺寸猜是单人还是 8 人图（单人图自动加 `$`）；尺寸切不开会拦下。游戏图片是加密的（System.json 的 `hasEncryptedImages`）就按游戏密钥存成 `.png_`（MV 是 `.rpgmvp`），不然存 `.png`。
- **替换**：把上传的单人图换进 8 人图里的某一格，其它格不动。
- **调整**：上下左右挪、缩放、左右翻转（翻转时朝左 / 朝右两行会对调）；可以覆盖原图，也可以另存成新的 `$` 图。
- **从三视图做**：AI 出的角色常常只有站立的正面、右侧、背面三张（比如 ComfyUI「立绘转高清像素小人」出的 `01_正面` `02_右侧` `03_背面`，或者一张从左到右排的三视图）。拖进来就拼成单人行走图：朝下 = 正面，朝左 = 右侧镜像，朝右 = 右侧，朝上 = 背面；三张按脚底对齐（最下面一排不透明像素的中点放在格子底部中间），正面缩到设定的身高（默认 96 像素，一格地图是 48）；走路的两帧会真的迈腿：正面、背面是左右脚轮流抬起（腿从两腿之间最空的那一列分成两半，抬起的那条从胯往下慢慢收上去，上半身跟着沉一点），侧面是一条腿往前、一条（暗一点的远腿）往后，迈成一个「八」字；腿从脚底往上 44% 的身高算起。「迈步幅度」可选正常 / 大步 / 小碎步 / 不迈步，对话框里有四个方向一起走的预览。可选外发光（金 / 红 / 蓝，氪金大佬的强化光）。存成 `$名字.png`。
- 覆盖原图前先备份到 `backups/…/images-时间/`。云端：上传的图放在当前用户的工作区 `img/` 下，导出改动包时按游戏密钥加密一起打包。

## 改台词

改台词用的是同一个合并核心（`core/merge.js`）：打开不改直接保存一定不改数据，改一句只动那一句；
条件、插件等原来的结构显示成 `■` 行，不能改，但可以在它们中间加台词。点「写法」看完整说明。

**演出和立绘也能在编辑框里写**（指令 ↔ 文字双向无损，原来游戏里这样的指令打开就显示成这种写法）：

| 写法 | 意思 |
| --- | --- |
| `#字幕 大一 · 九月` | 画面中间一条暗底的字（居中），几行用 `｜` 隔开 |
| `#立绘 林屿 笑 左` | 显示 `img/pictures/立绘/林屿_笑`，底边贴着画面下沿；位置 左 / 中 / 右 可以不写；同一个人再写一次 = 换表情 / 换位置。立绘用编号段最上面三个号，总在 CG 上面 |
| `#退场 林屿` / `#退场` | 收起这个人的立绘 / 所有立绘（`#清图` 不碰立绘） |
| `#淡出` `#淡入` | 画面变黑 / 恢复 |
| `#音乐 名字 80` `#停音乐 2` | 背景音乐（音量可以不写）/ 两秒内渐渐停掉；`#环境音` `#停环境音` 同理；`#音效 名字` |
| `#色调 夜晚 2` | 正常 / 夜晚 / 深夜 / 黄昏 / 回忆 / 灰暗 / 红，2 秒变过去 |
| `#震动` `#气泡 ！` | 画面震一下（强度 1~9）/ 主角头上冒气泡（后面写「本事件」= 这个事件头上） |
| `#场景 名字` | 在这里播另一个场景（调用公共事件） |
| `#行走图 林屿 图名 0` | 换角色的行走图 |
| `#透明 开` `#消失` `#独立开关 A 开` `#回到标题` | 主角隐身 / 这个事件先不见 / 这个事件自己的开关 / 回到标题画面 |
| `#飘字 林屿：是我的问题吗` | 字从人物头上一句一句飘起来再淡掉，不挡剧情（连着几句，前面的被顶上去）；不写名字 = 主角，`画面：` = 画面中间 |
| `#动作 赵磊 转身 ！ 下2 等0.5` | 按名字让人物动：上 下 左 右（可带步数）、转身、面向 / 背对主角、跳、后退、等几秒、速度、气泡；最后写 `不等` = 不等他做完 |
| `#镜头 上 4` `#天气 雨` `#闪光 红` | 镜头平移（速度 1~6）/ 天气 雨 暴雨 雪 无 / 画面闪一下 |

`#飘字` `#动作` 是演出插件 `RpgStudio_Stage` 的插件指令（MZ 里还带「谁 = …」续行，RPG Maker 编辑器里也看得懂）：按名字找人，所以写在场景（公共事件）里也行。第一次存用到它们的剧情时，编辑器自动把插件装进游戏（`js/plugins/RpgStudio_Stage.js`，并登记到插件列表）；新建的游戏直接带着。

一行台词太长（游戏里会被窗口截掉）时，保存后会提示拆行。

**选项可以改**：一个「显示选项」在编辑框里是「■ 选项（3 个）：A / B / C」（列出全部选项，空的写「（空）」，只是看的），下面每个选项一行「■ 选了「选项的字」」，再下面是选了它以后的内容，最后「■ 选项结束」。
- 改「」里的字 = 改这个选项（游戏里显示的选项和分支一起改）；
- 照着写一行「■ 选了「新的选项」」（放在「■ 选项结束」或「■ 按取消时」前面，最多 6 个），下面写它的台词 = 加一个选项；
- 删掉「■ 选了」这一行和它下面的内容（里面套着条件的话，那些 ■ 行也一起删）= 删掉这个选项。
- 加、删以后选项编号重新排；「按取消时选哪个」「默认选哪个」跟着挪，选的那个被删了就变成不能取消 / 没有默认。
- 「■ 选项（N 个）：…」那一行不用改（加、删、改了选项它不跟着变也没关系，保存后会重新列）；在这一行里改字不算数，会提示去改「■ 选了」。「■ 按取消时」「■ 选项结束」不能改。新的一整个选项用「#选项 去 | 不去」写。

**台词里的文字代码**：`\N[1]`、`\C[2]`、`\V[3]` 这些 RPG Maker 自带的代码，和 VisuMZ 文字插件的 `<center>`、`\LastGainObj`、`\Item[5]` 这类，
在阅读视图和预览里显示成游戏里的样子（`<center>` 居中，`\LastGainObj` / `\LastGainObjQuantity` 换成这句前面最近一次得到的东西和数量，
`\V[n]` 写成〔变量名〕，颜色、字号、等待这类去掉），鼠标停在台词上能看原文；改台词的编辑框里保持原文，代码标成灰色。

保存前会检查：只拦「保存后新出现的问题」，原来就有的问题不会让你什么都存不了。

## 游戏配置（profiles/）

不同游戏有不同约定，放在 `profiles/` 里，按分数自动选，也可以在「工程设置」里手动选：

- `generic.js`：通用。新图片从 1 号往上叠；只写 `#清图` = 关掉这一页自己显示的图（不碰别的编号，免得关掉界面图）。
- `example.js`：示例，默认不会被自动选中（`match` 返回 0），要用得手动选。里面把四种能力都摆了例子：图片编号段、剧情进度（按天 / 时段）、开关 / 变量 / 公共事件的说明、概览里的剧情骨架。编号都是占位的，照着换成你自己游戏的。

配置里可以写 `progress: { main: { type: 'day' | 'chapter' | 'switches', var, slots: [{ switch, label }], segs: [{ from, label }], chain: [{ switch, label }] }, tracks: [{ var, label }] }` 指定剧情进度，不写就自动识别。

新游戏想加约定：照 `example.js` 写一个，在 `profiles/index.js` 里登记。图片编号段也可以直接在「工程设置」里改（存在 `app/studio/data/settings.json`）。

挂到别的服务上：

```js
const { createStudio } = require('./studio/handler.js');
const studio = createStudio({ gameDir, dataDir, backupsDir, settingsFile });
// 在你的 http 处理函数里：
if (await studio.handle(req, res)) return;
```

`gameDir` / `dataDir` 可以传函数（云端每个请求切换到当前用户的工作区）。
再传 `projects: { dir, builtinName, maxUpload }` 就打开工程列表（`dir` 也可以是函数：云端每个用户一个）。

加一个功能模块：在 `routes/` 里写一个文件，返回 `{ get: { 路由(T, q) }, post: { 路由(T, body) } }`，在 `handler.js` 的 `MODULES` 里登记；
要用别的模块的视图就通过 `ctx.views`（eventView / ceView / mapView / personView / checkImage / tilesetOf / freeSlot …），调用别的动作用 `ctx.actions[…]`。
界面在 `web/js/` 里加一个文件，`index.html` 里按顺序加 `<script>`，`shell.js` 的 `render()` 里加路由。
